MATERIAL MASK

Metasiberia: R = detail 0 (rock), G = detail 1 (sediment/sand), B = detail 2 (vegetation). Every mask pixel is normalized so the channel sum equals 255. Trees are controlled by a separate black-and-white PNG mask.

TREES

Trees use a separate opaque black-and-white mask. White permits trees; black forbids trees. In Metasiberia, tree placement also requires the vegetation material channel (B / detail 2). ADD TREES now sets both masks together.

EXPORT COMPATIBILITY

Roads and buildings are independent reference masks. They do not alter the EXR or create parcels automatically.
EXR uses one float channel named Y. Current Metasiberia renders detail 1 as ground and B/detail 2 as vegetation; R/detail 0 and detail 3 are not rendered separately yet. Tree mask is opaque: white = trees and B vegetation, black = no trees.
